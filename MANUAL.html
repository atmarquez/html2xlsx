📘 Manual de Usuario — html2xlsx

🧭 Introducción

html2xlsx es una herramienta de línea de comandos diseñada para convertir documentos HTML en archivos Excel (.xlsx), manteniendo la estructura y la jerarquía del contenido original.

Está pensada para transformar páginas HTML complejas en documentos Excel organizados, legibles y visualmente consistentes.

🎯 Objetivo

  • Convertir HTML en Excel estructurado
  • Respetar jerarquía del contenido
  • Soportar tablas complejas
  • Gestionar imágenes correctamente
  • Preservar enlaces

✅ Características principales

  • Párrafos y texto enriquecido
  • Encabezados h1–h6
  • Listas anidadas
  • Tablas con rowspan y colspan
  • Imágenes (base64, HTTP, locales)
  • Enlaces internos y externos
  • Sistema de layout avanzado

▶️ Uso básico

python html2xlsx.py archivo.html

Genera automáticamente:

archivo.xlsx

⚙️ Opciones generales

--columns

Número de columnas utilizadas.

--columns 10

--column-width

Ancho de columnas.

--column-width 12

--no-images

Desactiva imágenes.

--no-tables

Desactiva tablas.

--no-links

Desactiva enlaces.

🖼️ Sistema avanzado de imágenes

--image-max-width

--image-max-width 800

--image-max-height

--image-max-height 400

--image-fit

  • contain: mantiene proporción
  • cover: rellena completamente
  • stretch: ajusta exactamente
--image-fit contain

--image-padding

Espacio vertical en filas Excel.

--image-padding 2

--image-background

--image-background F8F8F8

--image-align

  • left (default)
  • center
  • right
--image-align center

--image-border

Añade un borde exterior sin rejilla interna alrededor del bloque de imagen.

🧱 Composición visual de imágenes

python html2xlsx.py archivo.html --image-align center --image-background EEEEEE --image-padding 2 --image-border

Este comando genera un bloque visual tipo "card": - centrado - con fondo - con padding - con borde limpio

🧪 Ejemplos reales

Básico

python html2xlsx.py documento.html

Sin imágenes

python html2xlsx.py documento.html --no-images

Layout profesional

python html2xlsx.py documento.html --image-align center --image-background F8F8F8 --image-border

Control de tamaño

python html2xlsx.py documento.html --image-max-width 800 --image-max-height 400

⚠️ Limitaciones

  • No soporta CSS completo
  • No ejecuta JavaScript
  • Posicionamiento basado en columnas

🛠️ Rendimiento

  • Depende del tamaño HTML
  • Imágenes grandes aumentan tiempo
  • Tablas complejas consumen memoria

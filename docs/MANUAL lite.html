📘 Manual de Usuario — html2xlsx

Introducción

html2xlsx convierte documentos HTML en Excel (.xlsx) manteniendo estructura y formato.

Uso básico

python html2xlsx.py archivo.html

Opciones generales

--columns

--columns 10

--column-width

--column-width 12

--no-images

--no-images

--no-tables

--no-tables

--no-links

--no-links

Opciones de imágenes

--image-max-width

--image-max-width 800

--image-max-height

--image-max-height 400

--image-fit

contain | cover | stretch

--image-padding

--image-padding 2

--image-background

--image-background FFFFFF

--image-align

left | center | right

--image-border

Añade borde exterior

Ejemplos

Básico

python html2xlsx.py archivo.html

Layout profesional

python html2xlsx.py archivo.html --image-align center --image-background F8F8F8 --image-border

Sin imágenes

python html2xlsx.py archivo.html --no-images

Notas

  • Excel generado automáticamente
  • Imágenes ajustadas al layout
  • Compatible con tablas complejas

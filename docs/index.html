¿Qué es html2xlsx?

html2xlsx es una herramienta de línea de comandos desarrollada en Python que convierte documentos HTML en archivos Excel (.xlsx).

Respeta la estructura del contenido original e incluye soporte para texto, listas, tablas complejas, imágenes y enlaces.

Está pensada para automatización, generación de informes y migración de contenido web a formatos Excel.

Características principales

📄 Texto estructurado: encabezados, párrafos y formato automático.
📋 Listas: soporte completo para listas anidadas.
📊 Tablas: compatibilidad con rowspan y colspan.
🖼️ Imágenes: soporte para base64, HTTP y archivos locales.
🔗 Enlaces: internos y externos.
🎯 Layout avanzado: control total de imágenes y formato.

Motor avanzado de imágenes

html2xlsx incluye un sistema avanzado de maquetación de imágenes similar a CSS.

  • Alineación: left, center, right
  • Escalado: contain, cover, stretch
  • Fondo: color configurable
  • Padding: separación vertical automática
  • Bordes: solo exterior (sin rejilla)

Uso básico

Ejemplo de conversión:

python html2xlsx.py archivo.html

Opciones comunes:

--columns 10
--column-width 12
--image-align center
--image-background F8F8F8

Ejemplos

Básico 
python html2xlsx.py archivo.html
Layout profesional 
python html2xlsx.py archivo.html --image-align center --image-background F8F8F8 --image-border
Sin imágenes 
python html2xlsx.py archivo.html --no-images
